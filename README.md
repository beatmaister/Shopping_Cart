# Shopping Cart Application Readme

## Overview
- This is a shopping cart application.
- It requires permission to send notifications.
- Upon opening the app for the first time, you will be greeted with an empty cart.
- Navigate over to the inventory to begin adding items.
- Trying to add an item that is out of stock will prompt a dialog telling you it is unavailable.
- Trying to add an item that is already in the cart will give an option to cancel or increment its amount.
- The top of the cart page will keep track of your current total balance in the cart.
- You may download your shopping cart as a text file from the cart page.
- Once an item is first added to your cart, a notification will be sent telling you the cart is not empty.
- This notification will continue to be sent every 15 minutes while there are items in your cart.

## Technologies Used
- The app uses the Room dependency in order to manage the database.
- The app also used Google's Gson dependency to parse JSON data into the database.
- The app uses GitHub and my-json-server to host a JSON file as a mock API.
- Rawpixel.com was used to source the free PNG used as the app icon.
